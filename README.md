# Partido de Nations league españa 4-1 Croacia
El dia de ayer se jugo un partido de Nations league en el que españa ganó de forma aplastante a Croacia y que lo pone lider en su grupo con 7 puntos.

## **España como lider de grupo**
España se se pone como primero de grupo despues de ganar sus ultimos dos partidos ante *Inglaterra* y *Croacia*  ~
